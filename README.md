# Энергия · интерактивные демонстрации

Восемь интерактивных демонстраций по работе, энергии и её превращениям —
для объяснения темы у доски или за компьютером. Нумерация сквозная, поэтому
на уроке достаточно сказать «открой демо 5» и не искать по названию.

## Как запустить без интернета

Открыть файл `dist/index.html` двойным щелчком. Всё работает офлайн:
интернет и установка ничего не требуют, шрифты системные.

Это единственный файл, который нужен на уроке, — стили и код внутри него.
Его можно просто переслать: папка `dist/assets` для запуска не нужна.

Открывать двойным щелчком нужно именно `dist/index.html`. Корневой
`index.html` — точка входа для `npm run dev`, он ссылается на `src/` и сам
по себе покажет пустую страницу.

## Как выложить на Netlify

Вариант 1, без сборки: перетащить папку `dist` на app.netlify.com/drop.

Вариант 2, из репозитория: подключить проект, настройки уже в `netlify.toml`
(команда `npm run build`, публикуемая папка `dist`).

## Как пересобрать после правок

```
npm install
npm run build
```

`npm run build` доделывает за Vite один шаг: `tools/inline.mjs` вклеивает CSS
и бандл прямо в `dist/index.html`. Без этого Vite подключает бандл как
внешний ES-модуль, а такой модуль браузер отказывается грузить с протокола
`file://` — двойной щелчок давал бы пустую белую страницу.

Исходники в `src/demos/`. Ускорение свободного падения принято g = 10 Н/кг,
как в методичках, константа задана в `src/ui.jsx`.
