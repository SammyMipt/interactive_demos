# Энергия · интерактивные демонстрации

Восемь интерактивных демонстраций по работе, энергии и её превращениям —
для объяснения темы у доски или за компьютером. Нумерация сквозная, поэтому
на уроке достаточно сказать «открой демо 5» и не искать по названию.

## Как запустить без интернета

Открыть файл `dist/index.html` двойным щелчком. Всё работает офлайн:
интернет и установка ничего не требуют, шрифты системные.

Это единственный файл, который нужен на уроке, — стили и код внутри него.
Его можно просто переслать: папка `dist/assets` для запуска не нужна.

Открывать двойным щелчком нужно именно `dist/index.html`. Корневой
`index.html` — точка входа для `npm run dev`, он ссылается на `src/` и сам
по себе покажет пустую страницу.

## Ссылка в интернете

https://sammymipt.github.io/interactive_demos/

Публикуется через GitHub Pages из папки `docs` ветки `main`
(Settings → Pages → Deploy from a branch, ветка `main`, папка `/docs`).

`docs/index.html` — это тот же самодостаточный файл, что и `dist/index.html`,
его записывает `npm run build`. Поэтому после правок в `src/` порядок такой:

```
npm run build
git add -A && git commit -m "..." && git push
```

Без `npm run build` сайт останется со старым содержимым: в `docs` лежит
собранная страница, а не исходники.

## Как выложить на Netlify

Вариант 1, без сборки: перетащить папку `dist` на app.netlify.com/drop.

Вариант 2, из репозитория: подключить проект, настройки уже в `netlify.toml`
(команда `npm run build`, публикуемая папка `dist`).

## Как пересобрать после правок

```
npm install
npm run build
```

`npm run build` доделывает за Vite один шаг: `tools/inline.mjs` вклеивает CSS
и бандл прямо в `dist/index.html`. Без этого Vite подключает бандл как
внешний ES-модуль, а такой модуль браузер отказывается грузить с протокола
`file://` — двойной щелчок давал бы пустую белую страницу.

Исходники в `src/demos/`. Ускорение свободного падения принято g = 10 Н/кг,
как в методичках, константа задана в `src/ui.jsx`.

## Формулы

Формулы пишутся на LaTeX. В тексте — компонентом `Formula`, внутри сцены —
`SvgFormula` (оба из `src/ui.jsx`):

```jsx
<Formula tex="0{,}4\,mg" />
<SvgFormula tex="v = \sqrt{2gh}" y={90} width={250} height={40} size={20} />
```

KaTeX переводит LaTeX в MathML, а рисует его сам браузер своим
математическим шрифтом, поэтому шрифты KaTeX в файл встраивать не нужно.

Две тонкости. Единицы измерения передаются отдельным параметром `unit` и
остаются снаружи математики: в шрифтах KaTeX нет кириллицы, и «Н» внутри
`\text{}` осталось бы пустым местом. Числа с запятой пропускаются через
`texNum`, иначе LaTeX считает запятую знаком препинания и ставит после неё
пробел: нужно `12{,}5`, а не `12,5`.

У `SvgFormula` координата `y` — это верх блока, а не базовая линия, как у
SVG `<text>`. Размеры `width` и `height` заданы в единицах viewBox; если
формула в них не влезает, она обрежется.

## Состав

1. Работа и перемещение — коробку тащит сам ученик, ползунок массы
2. Масса и вес — Земля, Луна, Юпитер
3. Энергия как работа — тележка тормозит и поднимает груз
4. Нулевой уровень — пунктир перетаскивается мышкой
5. Шарик на горке ★ — три точки совпадают с таблицей из плана
6. Маятник — циклическое превращение, переключатель трения
7. Масса не влияет — два шара приезжают одновременно
8. Мяч и нагрев ★ — механическая энергия уходит во внутреннюю

Звёздочкой отмечены ключевые демонстрации.
